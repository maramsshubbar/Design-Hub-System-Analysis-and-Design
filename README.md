<h1 align="center">The Design Hub</h1>

<p align="center">System Analysis and Design · Bahrain Polytechnic</p>

## Overview

The Design Hub is a coursework project that explores how an organization could manage projects, volunteers, and donation requests in one place. The final report documents the system design, and a C# Windows Forms prototype shows how users would navigate key tasks.

## Prototype

The prototype includes screens for:

- Signing in, registering, and navigating the dashboard
- Creating projects and assigning tasks
- Requesting volunteers and donations

## Run the prototype

1. Clone or download this repository.
2. On Windows, open the linked solution in Visual Studio with the **.NET desktop development** workload installed.
3. Press **F5** to build and run the prototype.
